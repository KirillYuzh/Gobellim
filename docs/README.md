# Hello, Gobellim!

Gobellim — Go-библиотека для безопасных вызовов LLM.

Задача библиотеки — сделать работу с LLM лёгкой и с гарантированной безопасностью, как будто это часть привычной бизнес-логики.

## Быстрый старт

```sh
go get github.com/KirillYuzh/Gobellim
```

Минимальное приложение — [Быстрый старт](./overview.md).
Требования и сборка — [Установка](./installation.md).
