## Текущее состояние

Реализован **Этап 1 (ядро)** на чистом Go: фасад, единый примитив вызова, RBAC, guard L0/L1, адаптеры провайдеров, эмбеддеры (remote), чанкер, ES-слой, трейсы. Сборка по умолчанию (`go build ./...`) не требует нативных библиотек. ML-слой guard и локальный ONNX-эмбеддер стоят за интерфейсами и включаются сборкой с тегом `ort` (Этап 0/2). Проверка: `go build ./... && go test ./...`.
