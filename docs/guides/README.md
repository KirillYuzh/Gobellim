# Руководства (how-to)

| Тип         | Отвечает на вопрос            | Где в этом репозитории                                              |
| ----------- | ----------------------------- | ------------------------------------------------------------------- |
| Tutorial    | «Я новичок, проведи меня»     | [Начало работы](../getting-started/quickstart.md)                   |
| How-to      | «Как сделать X?»              | этот раздел                                                         |
| Reference   | «Что означает поле Y?»        | [Справочник](../reference/kit.md)                                   |
| Explanation | «Почему устроено именно так?» | [Основы](../concepts/chat.md), [Устройство](../internals/design.md) |

Страницы how-to **не дублируют справочник**: сигнатуры, таблицы полей и значения
по умолчанию живут в [справочнике провайдеров](../reference/providers.md) и
[конфигурации](../reference/configuration.md). Здесь — предпосылки, пошаговая
настройка, готовые сниппеты, рецепты, подводные камни и troubleshooting.
