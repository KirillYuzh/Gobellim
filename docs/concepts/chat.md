# Chat

Chat — одна операция. Она собирает историю, проверяет её guard'ом, выбирает
инструменты, доступные вызывающему, и крутит цикл «модель → инструмент → модель»,
пока модель не вернёт финальный ответ.

Операция идёт через единый примитив вызова: проверка прав, guard, span трейса,
выполнение. Второй точки входа нет, поэтому проверку нельзя обойти.

## Когда использовать

- Задача открытая, шаги заранее не известны. Модель сама решает, какой инструмент
  вызвать, сколько раз и когда остановиться.
- Ответ нужен по вашим документам и с вызовом внешних API в одном запросе.
- Модель должна отвечать от имени конкретного пользователя, с его ролями.

Для фиксированного сценария вызывайте операции напрямую — `Ingest`, `Search`,
`Delete`. Оркестрации, workflows и мультиагентности в v1 нет.

## Быстрый старт

```go
app, err := kit.New(ctx, kit.Config{
	ES:     es,     // ваш клиент Elasticsearch
	LLM:    llm,    // vLLM, Ollama, OpenAI-совместимый API или GigaChat
	Policy: policy, // authz.Load("policy.yaml")
})
if err != nil {
	return err
}
if err := app.Setup(ctx); err != nil { // один раз создаёт индексы
	return err
}

ctx = kit.WithPrincipal(ctx, kit.Principal{
	UserID: "u-1",
	Roles:  []string{"user"},
	Tenant: "acme",
})

answer, err := app.Chat(ctx, kit.ChatRequest{
	System:   "Ты ассистент поддержки. Отвечай кратко.",
	Messages: []model.Message{{Role: model.RoleUser, Content: "Какая погода в Москве?"}},
})
```

`kit.WithPrincipal` кладёт принципала в контекст. Без принципала операция вернёт
`ErrUnauthorized`. Системный промпт задаёт только приложение — в поле `System`.

## Как использовать

### История сообщений

В модель уходят только сообщения с ролями `user` и `assistant`. Клиентские роли
`system` и `tool` отбрасываются, `tool_calls` тоже. Каждое оставшееся сообщение
проходит guard входа.

Это защита от подделки истории клиентом: инструкции приложения нельзя перебить
сообщением из запроса.

### Цикл инструментов

На шаге цикла модель либо отвечает, либо просит вызвать инструмент. Для каждого
запрошенного вызова kit:

1. проверяет права повторно — уже на исполнении;
2. валидирует аргументы по JSON Schema;
3. проверяет лимиты: `MaxCallsPerTool`, `ToolTimeout`;
4. прогоняет результат через guard.

Цикл ограничен `MaxSteps` (по умолчанию 8). При исчерпании возвращается
`ErrMaxSteps`.

### Ответ целиком

Стриминга нет. Ответ буферизуется полностью, потому что guard выхода должен
видеть весь текст. Если нужен поток, его собирает ваш слой поверх готового ответа.
