# kit — Go-фреймворк для LLM, RAG и безопасных tools

Рабочее имя пакета `kit` (путь модуля `github.com/<org>/kit`, финальное имя выбирает команда). Версия документа: 1.0, дата: 2026-10-15.

## 1. Для кого и зачем

Команда на Go хочет получить инстанс модели, эмбеддер, поиск по Elasticsearch и tool calling без написания middleware, без LangChain-подобных абстракций и без Python в проде. После установки разработчик должен:

1. скачать модель эмбеддингов и guard-модель в `./models`;
2. передать в `kit.New` свой ES-клиент, LLM-клиент, эмбеддер и `policy.yaml`;
3. объявить tools и получить рабочие: ручку загрузки данных, поиск, чат с безопасным tool calling и трейсинг.

## 3. Границы (v1 как итоговая версия)

**Входит:** локальные и API LLM (vLLM, Ollama, OpenAI-compatible, GigaChat); локальные и удалённые эмбеддинги; токенный чанкер; ingest и гибридный поиск в ES (BM25 + kNN, RRF в Go); RBAC в YAML; guard с одной моделью gliner-guard-omni и детерминированным слоем; tool calling с вычитанием запрещённых tools; трейсинг в ES по модели Langfuse; JSON-API трейсов; дашборды Grafana.

**Не входит:** стриминг; мультиагентность, workflows, approval-флоу; ABAC; UI для трейсов; несколько хранилищ; удалённый guard; GPU-провайдеры ORT; обратимая анонимизация PII; Colang и диалоговые рельсы.

## 5. Что нового (кратко, по методике TRIZ + SIT + SCAMPER)

Три идеи, на которых сошлись все три метода (Merging/Universality, Task Unification, Combine; Prior Action, Subtraction, Eliminate; Prior Action, Attribute Dependency, Adapt):

1. **Единый примитив вызова** вместо пользовательских middleware: authz, guard и трейс неотделимы от вызова LLM, tool, эмбеддера и ES.
2. **Вычитание tools из схемы модели** плюс повторная проверка при исполнении.
3. **ACL при записи + фильтр принципала внутри kNN** (аналог row-level security).

Проверка prior art ограничена: поиск по доступным публичным источникам показал близкие по духу проекты на Go (galdor, Eino, langchaingo), но связки «RBAC в YAML + только ES + локальный guard + трейсы в той же ES» не нашёл. Это не юридическое заключение о новизне; для патентных целей нужен профессиональный поиск.
